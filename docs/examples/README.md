# Walkthrough previews

These standalone HTML files are generated by the commands in [the walkthrough](../index.html).
The workspace starts with `burr init`, then applies the tutorial’s premium-price scenario.

- `stand-dashboard.html`: base scenario, with price and discount-rate sliders.
- `stand-trends.html`: base, bear, and premium forecasts for revenue and profit.

To refresh them, run the walkthrough in a new workspace and copy
`artifacts/dashboard.html` and `artifacts/trends.html` here under these filenames.

## Starbucks previews

- `starbucks-dashboard.html`: sourced FY2025 baseline with traffic and margin sliders.
- `starbucks-trends.html`: reported history and illustrative scenario forecasts.

Regenerate via [the Starbucks guide](../../examples/starbucks/README.md), then copy
its `artifacts/dashboard.html` and `artifacts/business-trends.html` here under these names.
