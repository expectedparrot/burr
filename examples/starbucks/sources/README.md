# Starbucks source snapshot

[Starbucks FY2025 results release](https://investor.starbucks.com/news/financial-releases/news-details/2025/Starbucks-Reports-Q4-and-Full-Fiscal-Year-2025-Results/), published October 29, 2025.
Reviewed September 15, 2026. Retained numeric transcription: [reported.csv](reported.csv).

Use the annual columns for years ended September 28, 2025 and September 29, 2024.
The release labels these statements unaudited. All money amounts are USD millions;
shares are millions. Capex reverses the cash-flow statement’s negative outflow sign.
The `da` row comes from the cash-flow statement, not the smaller expense line in
the income statement. Each CSV row records its source table and row label.

Only annual operating observations enter `actuals.csv`. Balance-sheet values
remain here and support the capital bridge. No forecasts are inserted into facts.
This deliberately frozen FY2025 teaching baseline does not incorporate later
quarterly results, guidance, ownership changes, or transactions.
